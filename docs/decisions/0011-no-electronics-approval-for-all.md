# 0011 — 전기·소형비품을 빼고, 처분 승인은 모든 물품에 받는다

**맥락** — 🔴 전기·소형비품(`electronics`)은 "조건부 허용"으로 두고 UI·API·DB CHECK 3중으로 처분 승인을 강제했다(AGENTS 불변 3). 관리 정보에는 대장 등재·처분 승인·취득 재원 3개를 받았다. 기획팀 확인이 열린 항목이었다.

**결정** (QA 1차, 2026-09-29, 기획팀)
- 전기·소형비품 카테고리를 뺀다. 프로덕션에 이 카테고리 물품·관심은 0건이었다.
- 관리 정보는 **"내부 처분 승인을 받았어요" 하나, 모든 물품에 필수**. 등록 화면 물품 종류 아래에 늘 안내: "기관 및 지자체 물품 대장에 등재되지 않은 소모품만 나눔할 수 있어요. 내부 승인을 받은 뒤 등록해 주세요."
- 대장 등재·취득 재원·물품 히스토리 입력은 뺀다. 컬럼은 남기고 새 글은 `on_ledger=false`, `funding_source=NULL`, `history=NULL`.
- 게시물 수정 때마다 처분 승인을 다시 체크받는다 — 사람이 확인하는 법적 필드라 이전 값을 자동으로 넘기지 않는다(불변 4).

**결과** — 🔴 3중 방어는 없어졌다. 승인 강제는 UI(체크 없으면 버튼 비활성) + API(`lib/itemInput.ts`, 400). DB CHECK(`chk_red_needs_approval`)는 지웠다 — "모든 open 물품은 승인" CHECK는 승인 없이 올라간 기존 행(시연 물품 등) 때문에 두지 않았다. 데이터 초기화 뒤 넣을 수 있다.
카테고리를 바꿀 땐 여전히 `db/seed.sql`과 `ai/schema.js`를 같이 고친다. 순서: 문구·포장·공예·만들기·일회용품·행사·인테리어·폐홍보물·폐현수막·기타.

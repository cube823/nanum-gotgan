# 0007 — 권한 판정은 API가 DB로, 미들웨어는 리다이렉트만

**맥락** — Next.js 미들웨어(`proxy.ts`)는 edge에서 돌아 매 요청마다 DB를 못 본다. 그래서 `org_status` 같은 걸 JWT에 싣게 되는데, 승인되는 순간 토큰이 낡는다. 낡은 토큰이 권한을 주면 안 된다.

**결정** — 미들웨어는 JWT만 보고 **리다이렉트만** 한다(로그인/온보딩/관리자 화면). 쓰기 권한은 API에서 `requireUser()`/`requireVerified()`가 **DB를 읽어** 판정한다. 승인 후 클라이언트는 `session.update()`로 토큰을 갱신하지만, 그게 실패해도 권한이 새지 않는다.

**결과** — 게이트가 두 층이다: proxy(UX) + API(보안). 페이지마다 검사를 흩어놓지 않는다. 대가는 쓰기 API마다 `users` 조회 한 번 — 이 규모에선 무시.

# 0003 — 실시간 대신 5초 폴링

**맥락** — 채팅이 있으니 WebSocket이 자연스럽게 떠오른다. 그런데 사용자는 기관 담당자이고 하루에 몇 통 주고받는다. Vercel에서 WebSocket을 유지하려면 별도 서비스가 필요하다.

**결정** — 채팅방 5초 폴링(`?after=` 증분), 승인 대기 5초 폴링, 메시지 목록은 진입 시 1회.

**결과** — 인프라가 서버 하나 + DB 하나로 끝난다. 상대 화면에 즉시 뜨지 않는 5초는 이 사용자층엔 문제가 아니라고 봤다. **느리다는 피드백이 실제로 온 뒤에** 올린다. 폴링 커서는 `>=`로 두고 클라이언트가 id 중복 제거 — 같은 타임스탬프 유실을 막는다.

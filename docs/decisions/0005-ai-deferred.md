# 0005 — AI 토글은 MVP 밖

**맥락** — 03 기획서 목업에 토글 2개가 있다: `여러 물건 글쓰기`(사진 최대 30장, AI가 물건별로 분류해 초안 작성), `AI로 작성해요`. Replit 목업은 화면만 있고 뒤(DB·API 키)가 비어 있었다. 처음엔 이 AI 루프부터 설계했다.

**결정** — 순서를 뒤집는다. AI는 등록 화면의 **부가 기능**이고 없어도 사진 찍고 손으로 입력하면 등록이 된다. 등록→스와이프→채팅→양도 한 바퀴를 먼저 만든다. AI 코드는 `ai/` 패키지로 분리해 두고 web이 import하지 않는다.

**결과** — MVP 스키마에서 `item_drafts`·`created_from_draft`를 걷어냈다. 붙일 때 스키마 추가 + 토글 2개 + REVIEW 화면 1개면 되고 기존 코드를 고칠 일이 없다 (`MVP.md` §부록). **AI가 물품 사진을 제대로 분류하고 쓸 만한 한국어를 쓰는지는 아직 실측하지 않았다** — 골든셋 20장이 붙이기 전 조건이다.

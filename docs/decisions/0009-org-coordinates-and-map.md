# 0009 — 기관 좌표를 저장하고 카카오맵으로 보여준다

**맥락** — 기획 정의서 11(물품 상세)에 두 기관 위치 지도와 "약 n km"가 있다. `organizations.lat/lng` 컬럼은 처음부터 있었지만 전부 비어 있었고, 가입 때 새로 만드는 기관은 주소조차 받지 않았다. 그래서 직접 등록한 기관의 물품에는 지도가 영영 뜰 수 없었다 (로컬 물품 152개 중 150개).

**결정**
- 좌표는 **저장 시점에 한 번** 구한다 (카카오 로컬 API). 화면을 볼 때 부르지 않는다.
  - 시드 37곳: `web/scripts/geocode-orgs.mjs` → `db/orgs.sql` 끝의 UPDATE문. 역지오코딩으로 구가 주소와 맞는지 37/37 확인했다.
  - 새 기관: 가입 STEP 2에 **"기관 주소" 필수 칸**(Figma에 없다). `POST /api/orgs`가 좌표로 바꿔 저장하고, 못 찾으면 400.
- 거리는 **직선거리**(하버사인, `lib/items.ts` `DISTANCE_KM`). 도로 거리는 유료 경로 API가 필요하고, 서울 안 기관끼리는 "약 n km" 감이면 충분하다.
- 지도는 카카오맵 JS SDK, 보기 전용(끌기·확대 막음 — 시트 스크롤을 뺏지 않는다). 누르면 카카오맵 길찾기.
- 카카오를 택한 이유: 로그인에 쓰는 카카오 앱이 이미 있어 키·콘솔을 하나로 관리한다.

**결과** — 새로 가입하는 기관부터는 모든 물품에 지도가 뜬다. `KAKAO_REST_KEY`가 없거나 카카오가 죽으면 좌표 없이 저장하고 가입은 막지 않는다 — 그 기관 물품엔 지도·거리가 빠진다. 기관 정보 수정 화면이 없어서, 주소를 받기 전에 만든 기관은 운영자가 DB로 채워야 한다.

키: `KAKAO_REST_KEY`(서버), `NEXT_PUBLIC_KAKAO_MAP_KEY`(브라우저, 카카오 콘솔에서 도메인 제한). 둘 다 Vercel env에 있어야 한다.

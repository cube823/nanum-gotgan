# 로딩 상태 정의

**무엇**: 사용자가 무언가를 기다리는 모든 순간에 무엇을 보여 줄지. 원칙 → 유형 5가지 → 화면별 표.
**상태**: 2026-09-29 구현 — 아래 표의 ❌는 모두 고쳤다. 남은 건 "열린 것".
**왜**: 2026-09-29 점검 결과 서버 렌더 페이지 16개에 `loading.tsx`가 하나도 없고, 버튼 대부분이 눌러도 모양이 안 바뀐다.
모바일(싱가포르 서버 왕복 + 이동통신)에서는 "눌렀는데 아무 일도 없다"가 곧 "고장났다"로 읽힌다.

## 원칙

1. **누르면 100ms 안에 무언가 바뀐다.** 탭·카드·버튼 모두. 결과가 늦어도 "받았다"는 신호는 즉시.
2. **로딩과 비어 있음을 섞지 않는다.** 불러오는 동안 "대화가 없어요" 같은 빈 상태 문구를 띄우지 않는다.
3. **자리를 먼저 잡는다.** 스켈레톤은 실제 화면과 같은 틀(높이·간격)로 — 다 불러온 뒤 화면이 튀지 않게.
4. **기다리는 동안 두 번 누를 수 없다.** 진행 중인 버튼은 비활성 + 문구 변경. 서버도 막지만(트랜잭션) UI에서 먼저 막는다.
5. **백그라운드 갱신은 조용히.** 5초 폴링·탭바 배지·스와이프 기록은 표시하지 않는다.
6. **실패하면 로딩을 끝내고 이유를 보인다.** 로딩 표시가 남은 채 멈추지 않는다. 문구는 API의 한국어 에러 그대로.

접근성: 로딩 영역은 `aria-busy="true"`, 진행 중 버튼은 문구 자체가 바뀌므로 스크린 리더가 읽는다. 스피너만 두지 않는다.

## 유형

| 유형 | 언제 | 보여 줄 것 | 구현 |
|---|---|---|---|
| **A. 화면 전환** | 서버에서 DB를 읽어 그리는 페이지로 이동 | 그 화면 모양의 스켈레톤 (회색 블록, 은은한 깜빡임) | 라우트별 `loading.tsx` |
| **B. 첫 데이터** | 클라이언트가 처음 불러오는 목록 | 스켈레톤. 다 받은 뒤에야 빈 상태 판단 | 상태를 `null`(아직) / `[]`(없음)로 구분 |
| **C. 버튼 동작** | 저장·신청·확정 등 서버에 쓰는 동작 | 비활성 + 문구를 "~하는 중…"으로, 버튼 폭 유지 | `busy` 상태 / 서버 액션은 `useFormStatus` |
| **D. 업로드** | 사진 올리기 | 진행 개수("올리는 중 2/3") 또는 사진 위 스피너 | 파일별 카운트 |
| **E. 낙관적** | 결과가 거의 확실한 가벼운 동작 | 누르는 즉시 결과 반영, 실패 시 되돌림 | 로컬 상태 먼저 바꾸고 요청 |

스켈레톤 공통 모양: `bg-neutral-100 rounded-* animate-pulse`. 로고·아이콘 대신 **실제 레이아웃 틀**을 그린다.

## 404와 스트리밍

`loading.tsx`가 있는 라우트는 응답 머리(200)가 먼저 나가서, 페이지가 `notFound()`를 불러도 **HTTP 상태는 200**이고 본문에 404 화면 + `<meta name="robots" content="noindex">`가 온다 (`web/node_modules/next/dist/docs/01-app/03-api-reference/03-file-conventions/loading.md` "Status Codes").
로그인 뒤에만 보이는 서비스라 받아들였다 — 404 상태가 꼭 필요하면 proxy에서 걸러야 하는데 그건 DB를 proxy로 끌어들인다(불변 규칙 1 위반). smoke는 `nf()`로 "404 상태 또는 200+noindex+404 화면"을 404로 본다.

## 하지 않는 것

- 전역 상단 진행 막대(NProgress 류) — 스켈레톤과 중복. 라이브러리 추가 금지.
- 폴링·배지 갱신 표시.
- 300ms 지연 후 표시 같은 타이머 — `loading.tsx`는 빠르면 사실상 안 보이고, 버튼 문구 변경은 깜빡여도 무해하다.

## 열린 것

- **탭을 누른 순간 활성 표시**: 지금은 이동이 끝나야 탭 색이 바뀐다. 누른 탭을 로컬 상태로 먼저 칠할지 — 스켈레톤이 즉시 뜨면 불필요할 수 있어 구현 후 판단.
- 스켈레톤 블록은 `components/Skeleton.tsx`의 `Sk` 하나로 뒀다. 화면별 틀은 각 `loading.tsx`에.
